# Skill: docs-maintenance

## Objective
Documentation stays accurate and useful.

## What to Update
- `docs/installation.md` — if setup steps change.
- `docs/contributing.md` — if workflow or conventions change.
- `readme.md` — if project overview changes.
- `docs/ai-workflow/decision-log.md` — for architectural decisions.
- `docs/ai-workflow/problem-registry.md` — for bugs and their fixes.
- `.env.example` — if new environment variables are added.

## Checklist
- [ ] Changed APIs are reflected in documentation.
- [ ] New environment variables added to `.env.example`.
- [ ] Setup steps still accurate after changes.
- [ ] Decision log updated for non-trivial architectural choices.
